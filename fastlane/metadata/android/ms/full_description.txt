BearTube tidak menggunakan sebarang pustaka kerangka kerja Google atau API Youtube. BearTube cuma menghuraikan tapak web untuk mendapatkan maklumat yang perlu. Oleh itu, aplikasi ini boleh digunakan pada peranti tanpa perkhidmatan Google. Anda juga tidak memerlukan akaun YouTube untuk menggunakan BearTube, dan aplikasi ini sepenuhnya FLOSS.
