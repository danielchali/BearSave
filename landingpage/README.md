# BearTube landing page

A standalone static site built with plain HTML, CSS, and vanilla JavaScript. It has no framework, package manager, build step, or third-party runtime dependency. The BearTube icon is copied from the repository's existing landing-page assets.

## Preview locally

From the repository root:

```sh
python3 -m http.server 8080 --directory landingpage
```

Open <http://localhost:8080> in a browser. The page links to the canonical BearTube source, releases, license, and issue tracker on GitHub.
